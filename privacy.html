Scope & Privacy-First Architecture

This Privacy Policy explains how Devil's Trial: Adaptive Shuffling Traps ("we", "us", or "our") processes data when you interact with our web application, install our Progressive Web App (PWA), or run our open-source codebase locally.

Unlike conventional modern web applications that rely on persistent cloud databases, user tracking pixels, and profiling algorithms, Devil's Trial adheres strictly to a Local-First, Zero-Telemetry model. All game state computation, physics logic, and machine learning adaptations take place locally inside your browser's execution sandbox.

03

Information Processed & Stored Exclusively on Your Device

To preserve your progression across game sessions, Devil's Trial writes state information solely to your device's browser local storage (localStorage). This data is completely sandboxed to your browser's origin (window.location.origin) and is inaccessible to other websites.

The stored information includes:

  • Level Progression: The index of the highest level you have reached (currentLevelIndex).
  • Death Statistics: Total count of player deaths incurred across sessions (deathCount).
  • Visual Theme Preference: The active color palette chosen in settings (e.g., inferno, midnight, toxic).
  • Chaos Mode Setting: Whether dynamic trap shuffling is toggled on or off (chaosMode: true/false).
  • Timestamp: The ISO timestamp of your most recent auto-save (lastSaved).
  • Local AI Telemetry & Weights: Numerical feature vectors derived from your recent movement (jump frequency, rushing distance, reaction times, and trap efficacy counters).

Storage Engine & PWA 1:1 Shared Partition Guarantee

When you install Devil's Trial as a Progressive Web App (PWA) onto your desktop or mobile home screen, the application continues to run on the exact same web origin. Under modern W3C web standards:

  • The installed PWA window and the browser tab share the exact same local storage partition.
  • Levels cleared in the browser tab are immediately present when launching the PWA.
  • Your AI Director learning epochs are unified across both launch methods.
  • Total data footprint is approximately 1.5 KB to 4 KB, requiring a microscopic fraction of device storage.

Audio & Media Hardware Permissions

Devil's Trial relies exclusively on the browser's native Web Audio API (AudioContext) to synthesize retro 8-bit sound effects (jump bleeps, rolling boulder rumbles, metal sawblade slices, and victory chords) directly through mathematical wave generators (oscillators).

🎙️
ZERO HARDWARE RECORDING: Devil's Trial NEVER requests access to your microphone, camera, motion sensors, contacts, or media library. Audio output is generated strictly outbound to your speakers or headphones.
07

Service Worker & Offline Caching Policy

The game registers a lightweight Service Worker (sw.js) utilizing the browser's Cache Storage API (devils-trial-v3). The Service Worker operates under a Network-First Strategy:

  • Online Mode: Checks for the newest version of code files, AI parameters, and balance tweaks from the host server.
  • Offline Mode Fallback: If an internet connection is unavailable, it immediately serves precached HTML, CSS, JavaScript, and SVG assets so the game remains 100% playable anywhere without connectivity.
  • No user queries, personal logs, or gameplay inputs are cached or transmitted by the Service Worker.
08

Local Diagnostic Server Endpoints (Node.js)

When running Devil's Trial locally via the zero-dependency Node.js server (node server.js), two diagnostic endpoints are enabled:

  • GET /api/detect-storage-path?ua=...: Analyzes the requesting browser's User-Agent string to calculate the standard on-disk profile path where Chrome, Firefox, Edge, Brave, or Safari stores LevelDB files.
  • GET /api/open-storage-dir?path=...: Launches the native operating system desktop file manager (Windows File Explorer via PowerShell, macOS Finder via open, or Linux via xdg-open).
🔒
Strict Path Sanitization: The server strictly verifies that requested paths match known browser profile folders and local user AppData/Library directories. Arbitrary command execution is completely blocked. These endpoints only bind to your local loopback address (127.0.0.1).

Data Retention & Permanent Destruction Safeguard

Data stored in devils_trial_save_v1 remains on your device until you choose to clear it. You can permanently obliterate all saved state at any time via three methods:

  1. In-Game Destruction Button: Open the in-game Storage Menu (💾 DATA) and click "🔥 PERMANENTLY DESTROY ALL DATA & RESET". This instantly calls localStorage.removeItem('devils_trial_save_v1') and resets memory.
  2. Browser Settings: Go to your browser settings ➔ Privacy & Security ➔ Clear Browsing Data ➔ Cookies & Site Data.
  3. Developer Console: Press F12, enter the Console tab, type localStorage.clear(), and press Enter.
